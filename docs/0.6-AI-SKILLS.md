## 二、 三档模式 × 三类引擎智能双链系统（Smart WikiLink Engine）

1. 打开任意笔记，在右侧关联栏点击 **「提及」** 标签，顶部即为 **智能双链助手控制面板（`#smart-wikilink-panel`）**。
2. **三档触发模式开关（`#smart-wikilink-mode`）**：
   - **纯手工双链（`manual`）**：仅在手输 `[[` 或点击命令时触发，不主动扫描或修改正文。
   - **半自动 · 提醒双链（`semi-auto`，默认）**：实时扫描当前笔记正文，列出可关联的词项、目标笔记、识别引擎来源、余弦相似度与综合得分；支持点击单条 **「补链」** 或点击 **「一键自动补链」** 批量转为 `[[目标笔记]]` 或 `[[目标笔记|原文词]]`。
   - **全自动 · 保存时自动补链（`auto`）**：在保存笔记（`Ctrl+S`）或点击「一键自动补链」时，自动将正文中高置信度未加链词项补为标准双链（跳过 YAML、代码块、标题行与已有链接，同一目标笔记单篇最多自动补首次出现位置，且支持 `Ctrl+Z` 一步撤销）。
3. **三类底层识别引擎（`#smart-wikilink-engine`）**：
   - **离线算法：余弦相似度 + 词法实体（`offline-cosine`）**：先匹配全库笔记标题、去前缀标题与 `aliases` 别名；再计算当前段落与候选笔记的 128 维特征向量余弦相似度（Cosine Similarity），当段落余弦相似度达标且命中目标笔记核心概念词时，自动推荐 `[[目标笔记|核心概念词]]`。
   - **本地小模型：`SmolLM2-135M / Ollama`（`local-llm`）**：在离线余弦初筛基础上，调用本机 `127.0.0.1:11435` 本地小模型对候选双链进行语义确认与加权（标记为 `本地小模型确认`）。
   - **在线大模型：`Gemini 4`（`online-llm`）**：调用当前配置的在线大模型对跨领域概念关联做确认。

## 三、 核心技术架构与算法机制说明（产品技术白皮书记录）

| 模块 | 采用的核心技术与算法逻辑 |
| --- | --- |
| **万象星图与局部星图** | 将知识库建模为有向图 $G=(V,E)$，节点半径按中心性对数公式 $R(v) = R_0 + \alpha \ln(1 + \deg^+(v) + \deg^-(v))$ 动态计算；通过 Comlink Web Worker 在后台运行 `d3-force 3.0.0`（结合多体斥力 `forceManyBody`、边弹簧力 `forceLink`、防碰撞 `forceCollide` 及力导向/径向/目录聚类三类位置约束），设定 2.5 秒计算预算；局部星图采用 1~2 跳广度优先搜索（BFS）裁剪子图；布局坐标与视口保存在 IndexedDB（20 条 LRU 缓存，带节点集合哈希校验）。 |
| **智识检索与向量计算** | 四步流水线：① **Scope Gate 权限硬过滤**（仅允许选区/当前笔记/指定目录/指定项目/指定长稿/全库范围内的笔记进入后续阶段）；② **段落动态分块**（剥离 YAML，按标题层级与 600 字符窗口切分，保留精确起止行号与 `^block` 锚点）；③ **BM25 + 128 维余弦混合打分**（分词采用英文词项 + 中文 CJK 字与二元词 Bigram；BM25 计算词频饱和度与逆文档频率 IDF；同时用 32 位 FNV-1a 哈希将词项投影到 128 维带符号浮点向量并做 $L_2$ 归一化，计算余弦相似度 $\cos(\theta) = \mathbf{u}\cdot\mathbf{v}$；混合得分 $S = (0.72 \cdot S_{\text{BM25}} + 3.2 \cdot S_{\text{cosine}}) \cdot w_{\text{scope}}$）；④ **1-Hop 双链图扩展**（沿出链扩展一跳关联笔记补充上下文）。 |
| **受控差异修订（Diff）** | 基于双指针行级比对生成只读增删预览（`+`/`-`），绑定目标笔记永久 ID、磁盘 64 位 SHA-256 版本哈希与编辑器内存修订号 `revision`；应用时执行三重门禁校验，任何不一致立即拒绝写入。 |
| **长稿跨章节一致性核查** | 按 `chapter_order` 排序遍历范围内全部章节并输出完整核查清单与版本哈希；正则提取 `【实体·属性】：值` 建立跨章实体属性表检测前后设定矛盾，提取章节首个 `YYYY-MM-DD` 日期检测时间线倒置，结合图索引检测指向未创建笔记的 `[[断链]]`。 |
| **Skills 沉淀与脱敏分享** | 遵循 Agent Skills 规范生成含 `skill_id`、`source_notes`、`source_versions` 的结构化 Markdown；评测器执行 7 项章节与双链完整性校验，并比对来源笔记最新 SHA-256 前缀提示过期复审；脱敏导出器剥离私有 ID、Windows 盘符路径与 `sk-/rk-/pk-` 凭据。 |
