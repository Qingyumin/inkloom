# 0.5.3–0.5.4 工作台全功能收口：多维属性、手绘手帐、模板重建与长稿研究

日期：2026-10-24。Windows x64预览版，未签名。本版一次性完成0.5*可插拔工作台阶段全部功能：多维属性视图分组汇总、内联编辑与派生公式/关系汇总列，工作台模板包导出与导入重建，手绘手帐日历联动与白板嵌入SVG缩略图，行内嵌入预览与重复块标识自动去重，以及长稿章节排序汇编与研究引文复制；未包含AI、云协作或插件商店。

## 多维属性视图、派生公式与项目聚合

1. 活动栏选择“笔记视图”。除目录、标签、状态筛选外，提供分组下拉（不分组、按状态、按目录、按分类、按项目）与属性列选择（内置5项派生列：`formula:task_progress` 任务完成率、`formula:word_progress` 字数达成率、`formula:word_count` 正文字数、`rollup:project_notes` 项目关联数、`rollup:backlinks` 反向链接数，以及 `category`、`project`、`priority`、`target_words`、`author`、`year` 和全库已有YAML属性键）。
2. 选择属性列后，可按属性值筛选，也可选择“属性列”或“任务数”排序。
3. 顶部汇总栏实时统计全部匹配笔记的篇数、已完成篇数、内含Markdown任务完成进度（已完成/总任务），并在属性列为数值或派生公式时汇总合计与均值。
4. 启用分组后，上方展示各分组的篇数、任务完成数与数值合计，点击分组卡片可快速过滤该组。
5. 表格视图中，普通YAML属性列支持内联输入框直接修改，派生公式/关系汇总列渲染为只读徽章；属性修改复用64位SHA-256内容版本与脏状态检查，目标笔记若有未保存修改或磁盘版本变化则拒绝覆盖。
6. 工作台“项目”模块同步显示每个项目的任务完成进度与关联笔记数，与多维视图按项目分组的数据一致。

## 手绘手帐、白板缩略图与块引用增强

1. 白板库工具栏提供可选“手绘手帐日期”输入框与“今日手绘手帐”一键打开/创建按钮；指定日期的白板写入 `date: YYYY-MM-DD` 与 `journal` 标签。
2. 工作台月历同时展示结构化任务与带日期的手绘手帐（`手帐 · 标题`），点击日历中的手绘手帐直接打开对应白板画布。
3. 当正文中通过 `![[whiteboards/...]]` 嵌入白板时，预览区自动将 `excalidraw` 场景渲染为自适应 `viewBox` 的安全SVG矢量缩略图。
4. 独立段落 `![[...]]` 与段落行内 `![[...]]` 均渲染只读预览卡片，整篇文档共享24项/80000字符预算；当复制粘贴段落导致同一篇文档出现重复 `^block` 标识时，`deduplicateBlockIds` 自动保留首处并为重复处分配新唯一标识。

## 工作台模板导出与导入重建

1. 工作台顶栏提供“导出工作台模板”与“导入工作台模板”。
2. 导出生成 `inkloom.workspace-template`（version 1，上限256 KiB）JSON文件，包含模板名称、基底模板（`balanced`/`focus`/`writing`）、6个模块的网格几何坐标与尺寸、默认任务模式（清单/看板）及关联多维视图预设。
3. 导入时校验格式版本、字段范围、模块坐标边界以及模块间无重叠；存在重叠或非法字段时拒绝导入并保持当前工作台不变。
4. 持久化失败时自动回滚内存与界面状态，不留下半更新配置。模板仅保存布局与视图偏好，不打包或修改任何Markdown正文。

## 长稿章节排序汇编与研究引文

1. 活动栏“研究”提供“长稿”标签与“新建长稿”按钮。填写标题、目标字数（100至2000000）与写作提纲后，在 `manuscripts` 目录创建 `category: manuscript` 的总览笔记。
2. 长稿行自动汇总自身及关联章节的章节数与累计正文字数（剥离YAML、代码块与嵌入标记后的汉字与英文词数）。
3. 点击长稿行的“新增章节”，先校验长稿版本与干净状态，再在 `chapters` 目录创建 `category: chapter` 的章节笔记，并自动将 `- [[chapters/...]]` 与独立段落 `![[chapters/...]]` 追加到长稿总览笔记末尾。
4. 章节行支持直接调整章节序号（`chapter_order`）；点击长稿行的“汇编同步章节”按钮，按最新章节序号自动重排长稿中的 `## 章节结构` 与 `![[chapters/...]]` 嵌入顺序并打开全文预览。
5. 资料（`source`）与摘录（`excerpt`）行提供“复制引文”按钮，基于用户实际填写的作者、年份、来源标识或块引用生成标准Markdown引文并在界面回显；未知字段留空，绝不编造作者或年份。

## 可复现验证

在工作区根目录执行，使用隔离浏览器profile或临时Windows测试profile，不读写正式知识库：

```powershell
node --test --test-reporter=tap output/inkloom/core/*.test.mjs
& ([scriptblock]::Create((Get-Content output/inkloom/tools/test-native.ps1 -Raw -Encoding UTF8))) -ProjectRoot (Join-Path $PWD 'output/inkloom')
& ([scriptblock]::Create((Get-Content output/inkloom/tools/build.ps1 -Raw -Encoding UTF8))) -ProjectRoot (Join-Path $PWD 'output/inkloom') -ReleaseName 'Inkloom-0.5.4'
node output/inkloom/tools/verify-phase2.mjs --workspace
node output/inkloom/tools/verify-phase2.mjs --workspace --exe output/inkloom/release/Inkloom-0.5.4/Inkloom.exe
node output/inkloom/tools/verify-phase2.mjs --creation
node output/inkloom/tools/verify-phase2.mjs --creation --exe output/inkloom/release/Inkloom-0.5.4/Inkloom.exe
```

最终验收结论以 [发行报告](../verification/release-results.json) 中的0.5.4版本、测试计数与SHA-256哈希为准，发布通过后自动仅保留最近两个版本的发行包与验证产物。
