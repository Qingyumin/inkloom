# Inkloom 0.4 外观与验证

## 交付范围

1.7.3 起，入口为“活动栏底部设置 → 外观与主题 → 主题包与外观扩展”。该扩展区默认折叠，主题包、CSS、图标和 Banner 能力均保留。客户端色系切换会退出主题包覆盖；弹窗始终使用宿主颜色，不跟随主题包预览。

0.4.0在原设置窗口的“外观与主题”中提供主题包、图标包、正文CSS片段和本地Banner；图谱增加三种布局与三种节点样式，并可记住布局和视口。默认保留用户原有经典配色，不因升级自动更换主题或修改笔记。

内置主题为线稿、纸页、林间，各有深浅变体。卡片或选择器进入临时预览，应用后才保存；取消预览或关闭设置恢复已保存配置。保存失败时工作区和面板草稿都回退。设置、授权、错误弹窗仍使用宿主基础样式，主题包不能选择这些元素。

## 主题包

文件是UTF-8 JSON，不执行JavaScript，也不加载外站资源。必填字段：`format=inkloom.appearance`、`version=1`、`id`、`name`、`author`、`license`、`variants.light`和`variants.dark`。可选`css`与语义`icons`映射。

每个变体包含六位十六进制颜色：`base`、`secondary`、`ink`、`muted`、`accent`、`readerBg`、`readerInk`、`readerMuted`、`readerAccent`。基础文字与背景检查4.5:1对比度。尺寸限制：圆角0至8px、按钮28至34px、图标14至17px；字体类型为sans/book/kai。完整内置示例与校验器见 [appearance-presets.mjs](../core/appearance-presets.mjs) 和 [appearance-pack.mjs](../core/appearance-pack.mjs)。

主题包单文件最多500 KiB，自定义主题最多12个。导入后先校验和预览，内置ID不能被自定义包覆盖。导出只包含主题配置和来源信息，不包含笔记。桌面导出通过保存对话框新建JSON，已有文件不覆盖；浏览器通过下载输出。

正文CSS使用PostCSS 8.5.29与postcss-value-parser 4.2.0解析。仅允许h1至h6、p、blockquote、a、strong、em、code、pre、table、th、td、hr、li、mark等指定正文元素及白名单文字/边框/间距属性，运行时统一限定到阅读器内部。拒绝at-rule、CSS函数、URL、important、嵌套规则、任意ID/class选择器、定位、隐藏、负间距和超限字号。单片段最多16,000字符、80条规则。自定义CSS仍需预览检查可读性，不保证所有自选颜色组合均满足对比度。

## 图标包与规则

图标包字段为`format=inkloom.icons`、`version=1`、`id/name/author/license`、`assets`、`mapping`和可选`colorMode`。mapping仅允许file/folder/tag/star/daily/graph/database/search语义，不能替换保存、授权或错误处理命令。映射值为内置Lucide名称或`custom:资源名`。

图标包最多1 MiB、100个SVG，每个SVG最多24,000字符；最多保存6个包。DOMPurify净化后仅保留SVG基础形状、路径与几何属性，移除脚本、事件、外链、image/use/foreignObject/style等内容。默认跟随主题颜色，也可保留原色；失效或未知图标回退到Lucide。

图标可按当前笔记永久ID、目录或属性条件配置。优先级为笔记覆盖、最长目录匹配、属性条件；规则按库身份隔离。根目录规则覆盖子目录，更深目录可覆盖它。清除规则恢复继承，移除图标包不删除笔记。

## 本地Banner

只接受本地PNG/JPEG/WebP，原文件不超过8 MiB、4,000万像素；最长边压缩到1600px，单个压缩资源字符串不超过1,200,000字符。使用浏览器图像解码与Canvas转换，不引入在线图片服务。外观配置总JSON上限4 MiB，保存时移除不再引用的Banner资源。

应用范围为当前笔记、当前目录或全库默认。高度80至300px，水平/垂直焦点0至100%；“此范围不显示”阻断继承，“恢复继承”移除覆盖。总开关停用显示但保留配置。导出包含开关只在临时导出源文前加入图片，不写回Markdown；HTML文件已验证开关前后内容。Word/PDF沿用同一准备通路，本轮不宣称已逐页核对全部输出样式。

图片与规则存于profile设置。只移动知识库目录不会自动携带profile外观资源；分享主题包也不会包含个人Banner。

## 图谱

继续复用d3-force 3.0.0，提供力导向、径向约束环形和目录分组引力布局。节点表现为图集、线稿、星图；节点大小、间距、连线不透明度和布局记忆可在插件设置修改，布局与样式也可从全局图谱工具栏切换。

跨重启缓存按库、全局/局部、中心节点和查询范围隔离，只保存ID、坐标和视口，不保存正文。最多20条记录，按时间索引淘汰；布局键、节点身份集合和有限坐标均校验，不匹配则重算。计算中状态不作为完成布局恢复，预算内近似明确标记。缓存拒写时图谱继续可用并提示。停用插件释放Worker、事件和画布，不删除可重建缓存。

## 验证方式

沿用 [0.3验证说明](0.3-VERIFICATION.md) 的隔离profile和基础回归，新增`--appearance`专项。最新报告：[浏览器外观](../verification/appearance-browser-results.json)、[桌面外观](../verification/appearance-desktop-results.json)。交付须核对报告版本和时间；自2026-10-24起，中间候选与失败现场仅保留在最近两个版本内，超出窗口清理。

| 检查 | 实际操作 | 预期与回读 |
| --- | --- | --- |
| 主题与保护 | 依次预览三套深浅主题，读取工作区和设置弹窗计算样式 | 工作区改变、弹窗不被覆盖；取消恢复，应用持久化 |
| 文件往返 | 浏览器实际下载JSON，换测试ID后导入、应用并reload | 来源和格式保留，新主题恢复；保护选择器拒绝 |
| 配置拒写 | 仅令测试inkloom.settings写入抛QuotaExceededError，再应用主题 | 存储、工作区和面板均回退；解除后可继续操作 |
| CSS/SVG安全 | 导入含script、事件、远程image的SVG；提交import及越权选择器 | 净化或拒绝，未发生外部请求，旧合法样式保留 |
| 图标规则 | 对笔记、根目录和status条件分别应用图标并清除 | 优先级和继承生效，不改标题/字段/正文 |
| Banner | 选择本地测试图片，焦点0/0，目录继承、笔记隐藏与总开关；导出两份HTML | 图片实际加载，0%有效，覆盖可撤销，导出按开关包含/排除Banner |
| 图谱样式 | 切三种布局/样式，检查Canvas像素与持久化状态 | 非空、预算有效、同数据重开恢复 |
| 桌面重启 | 正常关闭自建EXE，再用同一profile启动 | 从持久缓存恢复，不把reload当进程重启 |
| 缓存拒写 | 仅让layouts.put抛配额错误，重新布局后解除 | 图谱可见、失败提示明确，之后可保存 |
| 原文与窄屏 | 全部示例前后回读，桌面另比原始字节SHA；390×844检查宽度 | Markdown/BOM/换行不变，面板无横向溢出 |

不包含任意Obsidian主题/插件兼容、视频Banner、在线素材、图标商店、自动更新和云同步。真人IME、辅助技术、隔夜稳定性与全量Office往返继续作为持续质量项目，不以截图替代。
