# 0.5.0 工作台与层级导航

日期：2026-10-23。Windows x64预览版，未签名。测试仅使用隔离profile和合成文件，不访问正式知识库。

## 入口与操作

1. 左侧文件栏按真实目录层级显示；点击箭头折叠，方向键上下移动、左右展开/返回父级。搜索保留祖先路径，当前笔记所在路径自动展开，原生版包含可访问空目录。
2. 活动栏“工作台”或`Ctrl+Alt+H`打开首页。顶栏铅笔开启拖动/缩放，模块菜单可隐藏模块，模板下拉切换日常/专注任务/阅读写作，恢复按钮回到默认布局。
3. “快速收集”选择Memo/任务/项目/阅读札记。Memo可只填正文，其余需要标题；保存后文件出现在memos/tasks/projects/reading目录。草稿自动保存在当前profile，不在未保存时生成半份Markdown。
4. Memo支持正文检索、每页20条、归档与恢复。点击标题进入原编辑器；归档仅把YAML的status改为archived，不移动或删除原文件。
5. 任务填写日期、可选提醒时间、优先级及项目；清单与月历同步。点日历日期进入该日任务收集，点事件打开原文。勾选和取消各只修改对应复选框字符，未保存/外部版本冲突拒绝覆盖。
6. 项目模板含目标、任务和相关笔记；首页统计项目内任务与关联任务。阅读札记包含来源、关键观点、问题和关联笔记，正文可自行修改。
7. 设置的“工作台与插件”可停用此组、配置启动后进入首页和应用内提醒。提醒默认关闭，仅应用运行时按本机日期/时间检查，每30秒一次；不是系统通知或退出后的后台服务。

## 数据与边界

任务使用CommonMark列表复选框，可写在任意笔记正文中；YAML、围栏代码和缩进代码中的示例不会成为任务。嵌套列表由markdown-it解析，保留BOM及原有换行。元数据例子：

```markdown
- [ ] 联系客户 @due(2026-10-23) @time(15:30) @priority(high)
```

日期须为有效的YYYY-MM-DD；时间为24小时HH:mm，需同时有日期；优先级为high/normal/low。元数据放在行内代码中不会生效。任务定位是永久笔记ID与当前源文位置，写入前重读内容及SHA-256并复核原行，不是跨任意正文重排都不变的块身份。

项目关联使用YAML的project记录当前知识库内永久项目笔记ID。仅复制Markdown到新profile时，需按既有身份清单迁移机制恢复ID；未实现自动猜测跨profile项目关联。任务复选框状态与表格/看板中的笔记status属性不是同一字段，不宣称两者自动同步。

后台收集采用稳定提交标识和独占文件移动。相同文件名及正文重试复用原文件；同名不同内容拒绝。保存成功不因关闭界面或停用插件而回滚。Markdown是已提交内容的唯一正文来源，profile内仅保留布局、设置与未提交草稿；profile丢失会丢失草稿和布局。

任务清单每页50条，Memo每页20条，首页项目最多50个、星标最多20篇，单个日历可见日期范围最多400条并显示截断提示。目录渐进加载默认200篇，搜索可定位后续文件；原生扫描仍受20000笔记/20000目录、约48MiB源文估算、单篇24MiB及64层保护。不是无限量资料库承诺。

本次不包含重复任务、任务看板、复杂时区/夏令时调度、退出后提醒、白板、正文嵌入、稳定块引用、公式/任意关系汇总、云同步或AI。

## 复用与许可

GridStack固定12.3.3，FullCalendar core/daygrid/interaction固定6.1.19，依赖Preact；根许可与对应包许可均为MIT，随发行物保留。不使用FullCalendar Premium、CDN或外部服务。GridStack与日历实现仅在打开工作台时加载。

本机通过本项目内下载并校验npm 11.6.1完整性后安装依赖，使用当前用户系统代理与系统CA，无提权或全局配置变更；未做从空node_modules开始的完整npm ci。安装工具见 [依赖安装](../tools/install-workspace-dependencies.ps1)。

## 可复现验证

以下命令在工作区根执行，Node 24与已安装的项目依赖为前置；Windows测试需要WebView2。脚本自动创建隔离profile并生成数据，失败保留现场，成功只清理自己创建的数据与进程。

```powershell
node --test --test-reporter=tap output/inkloom/core/*.test.mjs
node output/inkloom/tools/verify-phase2.mjs --workspace
node output/inkloom/tools/verify-phase2.mjs --workspace --exe output/inkloom/release/Inkloom-0.5.0/Inkloom.exe
```

| 检查 | 页面操作与数据 | 预期与回读 |

| 任务 | 填Workspace task acceptance、当前本机日期、重要，保存后勾选/取消 | 读取tasks原文件，除[ ]和[x]的一个字符外正文完全相同；月历出现事件 |
| 项目与模板 | 建Workspace project acceptance，再建Linked project task并选择该项目；建阅读札记 | 项目统计两项任务，project字段引用一致，阅读札记含关键观点等章节 |
